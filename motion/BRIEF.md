# BrAIan header loop

A 12-second, silent 1920×1080 loop for getbraian.github.io. Real app screenshots in a laptop and phone frame, adapted from HyperFrames' browser-device-stage component. Preserve exact UI pixels. Show Kanban and Spaces, hold the mobile reader alongside them, and return to the opening state for a gentle loop. Dark navy and periwinkle match the site. No narration, captions, music or stock footage. Render an MP4 for the website; keep the source editable. The page provides a pause control and a static poster for reduced-motion and data-saving preferences.
