05 / A shortcut to reading and writing

Ask a question.
Catch a thought.

Use AI when it helps. Ask about the vault, find context, or turn rough input into organised notes. The assistant works with the knowledge you have already built.

Choose the connection
for the job.

Add multiple providers and choose where each is used. OpenAI and OpenRouter API keys, Groq and OpenAI-compatible endpoints sit alongside experimental ChatGPT Codex, Claude and GitHub Copilot subscription connectors.

Chat, speech-to-text, embeddings and decision routing share one connection catalog. Choose the model and the enabled uses. Connect a cloud or local embedding endpoint; xAI is another speech-to-text option. New integrations can be added over time.

Subscription connectors are experimental; availability and permitted use depend on each vendor. Remote AI receives the context you send it.

Speak while the thought is fresh.

Use WhisperKit for local voice recognition and dictation through a compatible Mac server, or Groq for fast online speech-to-text. Dictate into notes or chat with the provider you choose.

Small decisions, quickly.

Jev provides fast decision routing through TypeSafe. Keep that role separate from your main chat model, and configure each connection for the capabilities it supports.

06 / Give someone the useful piece

A note for a friend.
A Space for the family.

Share one note, a folder, a board, an entire Space or a branch of its tree. Keep a family collection with your partner, or send just the context someone needs.

Write together.
Keep the boundary clear.

Give read or write access. Shared Markdown supports near-real-time collaborative typing, presence and multiple cursors—a familiar shared-document experience.

Create an expiring link or one with no end date. Revoke it when you need to. A Space or subtree link limits which items the recipient can open; your server must stay reachable.

Encrypted blocks are shared only when you choose to include them. This is a personal workspace with lightweight sharing.

08 / Still your files, all the way down

Build on what
you already own.

The workspace can grow. Your vault stays a folder you can inspect, back up and keep.

An Obsidian drop-in for core notes.

Point BrAIan at your existing Obsidian vault. Keep Markdown, filenames, folders and wiki links. Use both apps on the same folder at the same time; BrAIan picks up disk changes.

Simultaneous edits to one note use the last saved version. Obsidian plugins, themes and workspaces are not executed.

Local, or self-hosted.

Run on your computer, your VPS or a cloud server you control. The Docker setup serves app and API together with mounted vault and app-data folders. The public Docker image is coming soon.

Storage stays on that host. Optional remote AI, transcription, feeds and sharing use the network. Use HTTPS and a password for a remotely reachable instance.

Lock the note. Or just one detail.

Encrypt whole note bodies or selected blocks, including password and OTP blocks. Safe text stays encrypted on disk and out of search and AI reads. Titles, properties and attachments remain separate.

A few useful details

Is BrAIan a drop-in replacement for Obsidian?

For core Markdown-vault workflows, point BrAIan at the same folder without importing or converting your notes. You can keep both apps open on that vault. Edits from another app appear through filesystem updates; if both save the same note concurrently, the last write wins. Obsidian plugins, themes and workspaces are not executed by BrAIan.

Does anything leave my computer or server?

Your vault and application data are stored on the machine you run BrAIan on. BrAIan does not require a hosted storage account. Optional remote AI and transcription providers, RSS/newsletter connections and shared links communicate over the network. A browser on another device also retrieves content from your server.

Can I manage several vaults?

Yes. Register separate folders as independent vaults and switch between them. Each vault keeps its own notes, topology, views and feature settings.

Can I install it on Android or iOS?

Yes. Open your running BrAIan app on your phone and add it to your home screen for a native-feeling web app. The phone still needs to reach your BrAIan server. See the mobile installation steps.

Are Docker and Electron available?

Public Docker images and packaged Electron desktop releases are coming soon. You can run the published app today with npx braian.

Can I run BrAIan today?

Yes. The app is published on npm as braian. Run npx braian with Node.js 22.16 or later. Keep the terminal open while you use it.

Is the source code available?

The public repository currently contains documentation and an MIT license. We will add the application source code as soon as possible.

Do I need an AI account?

You can work with notes and views without connecting a model. The AI assistant needs a provider configured in Settings → AI providers. Your provider’s usage terms and charges apply.

Where does my data live?

By default, application data lives in .brian in the current folder. Use -g for ~/.brian or --data <directory> to choose a location. Your vaults hold the notes themselves. Do not run two app instances against the same application data folder.
