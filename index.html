Your vaults. Your choice.

One workspace.
Many vaults.

Keep work, personal notes and side projects in separate vaults. Switch between them without mixing their files, structure or settings.

A vault is an ordinary folder. Notes are Markdown, structure and view definitions are YAML, and attachments stay beside your content.

BrAIan stores your workspace on the machine that runs it. That can be your laptop, your own VPS or a cloud server you control. A local search index supports the files; you can inspect and back up the vault yourself.

Bring the vault you already have

An Obsidian replacement.
Or a new way alongside it.

Drop in your existing vault.

Point BrAIan at your Obsidian folder and start browsing, searching and connecting your notes. Keep the filenames, folders, Markdown and wiki links you already use. No import or conversion is needed for core Markdown notes.

Keep both apps open.

Use BrAIan and Obsidian on the same vault at the same time. They work on the same files, and BrAIan picks up changes made on disk.

Simultaneous edits to the same note use the last saved version. BrAIan supports core note conventions and the Excalidraw note format; it does not run Obsidian plugins, themes or workspaces.

A private layer inside your vault

Lock the whole note.
Or just the sensitive part.

Use encrypted notes for a private document, or encrypted blocks inside an otherwise ordinary note. Safe text stays encrypted on disk and is excluded from search and AI reads.

Local-first. Self-hosted when you want.

Your computer.
Your VPS. Your cloud.

Start on your computer.

Run npx braian and keep the server, notes and app data on your own machine. You do not need a BrAIan-hosted account to store your vault.

Deploy with Docker.

BrAIan’s Docker setup serves the app and API together. Mount your vault folders and application data, then put the instance behind HTTPS with a password on your VPS or cloud host.

The public Docker image is coming soon. Deployment instructions will accompany the image release.

Choose what connects.

File storage stays on your chosen machine. Optional remote AI and transcription providers receive the context or audio you send them; feeds and sharing also use the network. Choose those connections yourself.

A few useful details

Is BrAIan a drop-in replacement for Obsidian?

For core Markdown-vault workflows, point BrAIan at the same folder without importing or converting your notes. You can keep both apps open on that vault. Edits from another app appear through filesystem updates; if both save the same note concurrently, the last write wins. Obsidian plugins, themes and workspaces are not executed by BrAIan.

Does anything leave my computer or server?

Your vault and application data are stored on the machine you run BrAIan on. BrAIan does not require a hosted storage account. Optional remote AI and transcription providers, RSS/newsletter connections and shared links communicate over the network. A browser on another device also retrieves content from your server.

Can I manage several vaults?

Yes. Register separate folders as independent vaults and switch between them. Each vault keeps its own notes, topology, views and feature settings.

Can I install it on Android or iOS?

Yes. Open your running BrAIan app on your phone and add it to your home screen for a native-feeling web app. The phone still needs to reach your BrAIan server. See the mobile installation steps.

Are Docker and Electron available?

Public Docker images and packaged Electron desktop releases are coming soon. You can run the published app today with npx braian.

Can I run BrAIan today?

Yes. The app is published on npm as braian. Run npx braian with Node.js 22.16 or later. Keep the terminal open while you use it.

Is the source code available?

The public repository currently contains documentation and an MIT license. We will add the application source code as soon as possible.

Do I need an AI account?

You can work with notes and views without connecting a model. The AI assistant needs a provider configured in Settings → AI providers. Your provider’s usage terms and charges apply.

Where does my data live?

By default, application data lives in .brian in the current folder. Use -g for ~/.brian or --data <directory> to choose a location. Your vaults hold the notes themselves. Do not run two app instances against the same application data folder.
