Install BrAIan on Android or iOS for a native-feeling experience: your own home-screen icon and a dedicated app window. Open a note, check a task or capture a thought with a tap.

iPhone & iPad

Open your running BrAIan instance in Safari. Choose Share → Add to Home Screen, leave Open as Web App enabled when shown, and tap Add.

Apple’s install guide ↗

Android

Open your instance in Chrome. In the browser menu, choose Add to home screen → Install when offered. Menu wording can vary by device.

Chrome’s install guide ↗

Install the running BrAIan app, rather than this landing page. Your phone needs access to that server: use an HTTPS address and set a password before exposing it. Home-screen installation does not make the server available offline.

The full toolkit

Grow into it.

Enable the features your vault needs. Everything below is part of BrAIan’s current toolkit; public Docker and Electron releases are still on the way.

01 Capture & write

Rich Markdown notes

Write with live preview, slash commands, tables, checklists, links, folding and an outline. Open source mode when you need the Markdown.

Daily notes

Capture quick thoughts into dated notes and return to the day’s context from the calendar or Spotlight.

Journals

Keep dated writing in dedicated journals, browse activity and use optional AI reflection prompts.

Dictation & audio

Speak into notes or chat with a configured transcription provider. Record audio and keep it with the note.

Attachments

Drop or paste images and files into notes. Preview supported media and keep references with the content.

Video recording

Capture screen, camera and microphone sources into a recording folder with a note. Available sources depend on the browser and device.

Drawings & diagrams

Use Excalidraw notes for visual thinking, Mermaid for diagrams, and QR blocks for addresses worth sharing.

02 Organise & plan

Kanban

Arrange notes in columns, add card properties and open the full note beside the board.

Calendars

Put notes on a calendar through rules, connect external iCal feeds and link events to useful context.

Prioritization

Place notes on a configurable two-axis matrix to compare urgency, importance or your own criteria.

Spaces

Gather notes, folders, files and views into a tree. Work across tabs and split panes without moving the original files.

Dashboards

Build a front page from widgets such as recent notes, bookmarks, daily notes, clocks and embedded views.

Discovery

Combine nested rows with typed columns, filters and sorting. Optionally keep the note folders in step with the view.

IDE sessions

Focus a file explorer on a folder and work across split editor panes. Named sessions remember your working layout.

03 Connect & explore

AI assistant

Ask about your vault, structure rough input and update notes through typed tools. Choose providers, models, agent profiles and enabled tools.

Typed notes & views

Give people, tasks and projects their own properties, templates, table views and cards. Connect records with typed links.

Visual topology

Design the types and relationships your vault uses, with YAML definitions you can inspect on disk.

Graph explorer

Follow the connections between notes and inspect the relationships that bring your knowledge together.

RSS & newsletters

Follow feeds and supported email newsletter sources. Read articles, organise tags, star entries and keep reactions or notes.

Spotlight & keyboard navigation

Find notes and board cards, capture text, switch views and reach commands from the keyboard.

04 Share & keep

Sharing & live writing

Share notes, folders, boards and Spaces with revocable links. Choose read, write or dictation access and an expiry.

Safe Notes

Encrypt whole notes or selected blocks. Keep password and OTP blocks; encrypted text stays out of search and AI reads.

Git versioning

Keep vault history, inspect changes and recover earlier content with Git available on the server.

Files & code

Browse your vault’s folders, preview files, edit text and code, and move, rename, zip or download entries.

SQLite browser

Open a SQLite database, browse tables, run SQL and keep your query tabs with the vault.

Document exports

Export notes to PDF, Word or plain text, and download folders as ZIP files. Some exports need optional server tools.

Multiple vaults & passwords

Keep workspaces in separate folders, turn features on per vault and protect access to the running instance with a password.

A few useful details

Can I install it on Android or iOS?

Yes. Open your running BrAIan app on your phone and add it to your home screen for a native-feeling web app. The phone still needs to reach your BrAIan server. See the mobile installation steps.

Are Docker and Electron available?

Public Docker images and packaged Electron desktop releases are coming soon. You can run the published app today with npx braian.

Can I run BrAIan today?

Yes. The app is published on npm as braian. Run npx braian with Node.js 22.16 or later. Keep the terminal open while you use it.

Is the source code available?

The public repository currently contains documentation and an MIT license. We will add the application source code as soon as possible.

Do I need an AI account?

You can work with notes and views without connecting a model. The AI assistant needs a provider configured in Settings → AI providers. Your provider’s usage terms and charges apply.

Where does my data live?

By default, application data lives in .brian in the current folder. Use -g for ~/.brian or --data <directory> to choose a location. Your vaults hold the notes themselves. Do not run two app instances against the same application data folder.
